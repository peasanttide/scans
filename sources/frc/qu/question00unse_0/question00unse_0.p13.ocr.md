tive de l’équilibre entre les intérêts divers qu ils
îrouvoient établis. Ne pouvant les rompre, ils
les ont opposés les uns aux autres ; ne pouvant
leur faire poser les armes , ils ont tâché de leur
en donner d’égales ; de peur qu’aucun d’eux n’u-
