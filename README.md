# scans
scans of primary sources from the French revolution


terms
- scan : a digital file of a physical artifact. includes attribtuion to where it comes from, 
- collection : some logical grouping. like a newspaper or a dude's diary.
- issue : like a day's paper. a letter, a phamplet, a map, a book, a play, and list of issues / pages.
- page : a page. includes ocr, scan (and page in scan).
- image : an image. includes scan (and page in scan) and cropping bounds.
